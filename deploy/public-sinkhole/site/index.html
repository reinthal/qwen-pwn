{{html .Host}} is a security research sinkhole

This domain was registered defensively because an open-weight language model generates it as a file-upload and script-download address when acting as an agent. It was unregistered, so anyone could have claimed it and received those requests.

  • Nothing is served. Every request gets an empty-effect response (404, or 403 for uploads). No scripts or binaries are ever returned.
  • Uploads are rejected and request bodies are never stored or logged.
  • Minimal logs: time, method, host, path (query string removed), status, user agent, and the client IP truncated to /24 (IPv4) or /48 (IPv6). Kept for 30 days, used only to measure how often agents contact this domain.

If your systems contacted this domain, an AI agent you run likely followed a model-generated URL. Review that agent's tool permissions and outbound network access.
